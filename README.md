## What I build

### Arivo PMS — Property management system for hotel front desks *(sole developer)*
Reservations, walk-ins, an append-only folio/billing ledger, housekeeping, and automated night audit.
- **Multi-tenant** across ~30 tables with PostgreSQL row-level security + a RESTRICTIVE isolation policy for strict per-property data separation
- **Append-only folio ledger** with automated night-audit charge posting and checkout balance enforcement — real hotel accounting, not mutable records
- `React` · `TypeScript` · `Vite` · `Supabase (Postgres)` · `Stripe` · `Vercel`

Online check-in that takes load off the front desk, synced in real time with the staff PMS.

- Integrated a **channel manager** — two-way availability/rate push and booking ingestion via webhooks
- `Next.js` · `TypeScript` · `Supabase` · `Stripe`

Both run on a single Postgres backend with row-level security, built to production standard and deployed.
